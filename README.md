# Paws Petshop

Website modern untuk petshop dengan tema putih bersih dan aksen warna ungu-pink yang playful.

## Color Palette

- **Primary**: `#8b5cf6` (Purple) - Warna utama yang playful dan friendly
- **Secondary**: `#ec4899` (Pink) - Aksen untuk gradient dan highlight
- **Background**: `#ffffff` (White) - Base putih bersih
- **Text Dark**: `#1f2937` (Dark Gray)
- **Text Light**: `#6b7280` (Medium Gray)
- **Accent**: Gradient Purple to Pink

## Features

- Layanan: Makanan Kucing, Adopsi, Shelter, Grooming
- Produk makanan kucing dengan gambar
- Informasi kontak dan lokasi
- Google Maps integration
- Floating WhatsApp button
- Responsive design
- Modern gradient effects

## Tech Stack

- Svelte 5
- Vite
- Pure CSS (no frameworks)

## Development

```bash
cd petshop-paws
npm run dev
```

Server running at `http://localhost:5174`

## Design Philosophy

Menggunakan warna putih sebagai base dengan aksen purple-pink yang:
- Playful dan friendly untuk hewan peliharaan
- Modern dan clean
- Tidak terlalu maskulin atau feminin
- Cocok untuk semua jenis hewan peliharaan
- Memberikan kesan profesional namun approachable
